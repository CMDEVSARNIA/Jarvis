J.A.R.V.I.S.PART 01 · KEYS
PART 01

Keys

Three things Jarvis needs to work: a fresh Claude API key, a spending cap, and a Telegram bot. All done in your browser and on your phone.

A · Claude API key

  1. 1Open platform.claude.com and sign in.
  2. 2Go to API Keys. Delete the key you pasted into the chat earlier.It's in a chat transcript now, so it has to be treated as compromised.
  3. 3Click Create Key, name it jarvis, and copy it into Notepad.It starts with sk-ant-api. You can only see it once.
  4. 4Open Limits and set a monthly spend limit, e.g. $10.Jarvis runs unattended; this is your safety net.

B · Telegram bot (on your phone)

  1. 5In Telegram, search @BotFather (blue check mark) and open the chat.
  2. 6Send /newbot. Name it Jarvis, then pick a username ending in bot.e.g. yourname_jarvis_bot. It has to be unique on Telegram.
  3. 7BotFather replies with a token like 123456789:AAF…. Copy it into Notepad.Telegram Desktop on the laptop makes copying easier, but the phone works too.

Your notepad

CLAUDE KEY · sk-ant-api… (paste into Notepad, not here)
TELEGRAM TOKEN · 123456789:AAF…
CHECKPOINT

Notepad holds two things: a new Claude key and a Telegram token. The old key is deleted.

J.A.R.V.I.S.PART 02 · SERVER
PART 02

Server

A small Google Cloud machine that stays on 24/7 so Jarvis is always reachable. The machine itself is free tier; Google charges about $3.65/month for its public address. Google's screens change now and then, so labels may differ slightly.

A · Account and budget alert

  1. 1Go to console.cloud.google.com and sign up. Add your card when asked.New accounts usually get free trial credit that covers the first months.
  2. 2Open Billing → Budgets & alerts → Create budget. Set $5 and keep the email alerts on.

B · Create the machine

  1. 3Go to Compute Engine → VM instances. Click Enable if asked (takes a minute), then Create instance.
  2. 4Name: jarvis · Region: us-central1 (or us-east1 / us-west1).Only these three regions are in the free tier.
  3. 5Machine type: series E2, e2-micro.
  4. 6Boot disk → Change (may be under OS and storage): Ubuntu, Ubuntu 24.04 LTS, disk type Standard persistent disk, size 30 GB. Click Select.
  5. 7Leave everything else as it is. Click Create and wait for the green check mark.
THE ONE SETTING THAT COSTS MONEYThe default disk type is Balanced, which is not free. Make sure step 6 says Standard persistent disk before you click Create.
CHECKPOINT

The VM list shows jarvis with a green check mark and an SSH button next to it.

J.A.R.V.I.S.PART 03–04 · INSTALL & CONNECT
PART 03

Install

Click SSH next to your VM, then Authorize. In the terminal, paste each line (Ctrl+V or right-click → Paste), press Enter, and let it finish.

$ git clone https://github.com/cmdevsarnia/jarvis.git
$ cd jarvis
$ bash deploy/setup-server.sh            # 2–4 minutes
$ .venv/bin/python -m jarvis.configure   # answers below
$ sudo systemctl restart jarvis
THE SETTINGS TOOL ASKSYOU ANSWER
Anthropic API keyPaste from Notepad. Nothing appears while you paste; that's normal.
Which model?1 for Sonnet 5.5, the lower-cost choice.
What should Jarvis call youYour name, or "sir".
Bot tokenPaste the Telegram token (also hidden).
Your chat idLeave blank for now. Press Enter.
Set up phone calls now?N. That's Session 2.
IF GIT ASKS FOR A PASSWORDYour repository is private. Make it public (repo → Settings → Change visibility; it holds no keys) or use a GitHub personal access token as the password.

PART 04Connect Telegram

  1. 1On your phone, message your bot hello. It replies "Your chat id is …"
  2. 2In the SSH window, run .venv/bin/python -m jarvis.configure again. Press Enter to keep each answer until chat id, then paste it.
  3. 3Run sudo systemctl restart jarvis.
SESSION 1 COMPLETE

Text the bot "What's the server's CPU load?" and get a reply. Jarvis now runs 24/7; you can close the laptop.

J.A.R.V.I.S.IF SOMETHING GOES WRONG
DIAGNOSTICS

Troubleshooting

Most problems show up in the logs. In the SSH window, journalctl -u jarvis -n 50 prints the last 50 lines.

SYMPTOMFIX
Bot never repliesRun systemctl status jarvis; it should say active (running). If not, read the logs. Check the bot token is correct.
Bot keeps replying with your chat idThe chat id isn't saved yet. Repeat Part 04, steps 2–3.
"My API key was rejected"The Claude key is wrong or deleted. Create a new one and re-run the settings tool.
"I'm being rate limited"Check your credit and spend limit at platform.claude.com.
Logs say 409 ConflictAnother copy of Jarvis is using the same bot. Only one may run per bot token.
setup-server.sh stops with an errorScreenshot the last 20 lines (keys cropped out) and send it to Claude.
Google bill higher than expectedCheck the disk type is Standard and the region is one of the three free-tier regions.

Everyday commands

$ systemctl status jarvis                    # is it running?
$ journalctl -u jarvis -n 50                 # recent logs
$ cd ~/jarvis && .venv/bin/python -m jarvis.configure   # change settings
$ sudo systemctl restart jarvis              # apply changes
$ cd ~/jarvis && git pull && sudo systemctl restart jarvis   # update

On Telegram, send /reset to clear the conversation.
